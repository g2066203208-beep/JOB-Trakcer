# CAE 成果展示与原始数据索引

当前只建立**展示规范和索引**，尚未上传新的 Abaqus、LS-DYNA 等模型或云图，不把空目录写成“作品已发布”。

## 每个案例建议结构

```text
成果/
  CASE-XXXX/
    README.md               # 说明与文件索引
    figures/                # 图片：带工况、单位与图注
    tables/                 # CSV/TSV 结果（可公开的小体积）
    reports/                # 公开技术报告 PDF
    run-info.md             # 输入文件、日志、软件/版本、复现步骤
    checksums.sha256        # 文件哈希，用于校验
```

对大型 `.odb`、`.sim`、`.d3plot`、`.outb` 等，应在 `README.md`写存放位置、访问权限、文件大小、哈希；不要直接把数 GB 文件推到普通 Git 历史。

## 最小展示质量

- **几何/网格图**：方向、尺寸/单位、网格数、单元类型、版本。
- **计算云图**：变量、单位、色标范围、变形倍率、工况和时间步。
- **曲线**：横纵坐标、单位、通道名、原始数据来源、统计区间。
- **对比图**：统一物理意义、参考图与本人结果明确区分；标注误差计算口径。
- **技术说明**：边界/载荷依据、校核、异常和模型局限。
- **对外发布**：只公开有授权和非涉密的自有成果。

正式放入结果文件后再编辑网站 `data.js` 的案例描述和成果状态。

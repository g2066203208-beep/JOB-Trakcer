# CAE 学习资料与参考资源库

此目录按以下类别归档**有来源、版本、使用许可**的材料，网页初版先给出官方站点入口，不暗示已经下载各厂商完整文档。

- **有限元基础**：课程笔记、控制方程、单元与网格、误差和验证。
- **Abaqus**：官方帮助、用户手册、求解器版本差异、练习记录。
- **ANSYS**：Mechanical 求解与官方帮助链接。
- **LS-DYNA**：关键词/材料/接触文档，显式分析和验证案例。
- **SolidWorks / CAD**：几何清理和模型交换注意事项。
- **动力学与疲劳**：模态、PSD、Rainflow、DEL、载荷回放。
- **NAFEMS/标准验证**：官方基准、对照条件、误差分析模板。
- **跨行业案例**：机械设备、支架/结构件、汽车零部件、新能源等。

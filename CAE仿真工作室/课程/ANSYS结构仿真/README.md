## 课程结构

| 模块 | 节次 | 学习内容 |
|---|---|---|
| 几何建模与理想化 | 01—02 | SpaceClaim 几何清理、分割、参数化、抽中面、抽梁、节点连接 |
| 网格理论与划分 | 03—05 | 有限元单元基础、全局/局部网格控制、网格质量 |
| 连接与评定 | 06—07 | 接触设置、焊缝与螺栓建模、结果后处理校核 |
| 光伏支架案例 | 08—09 | 梁/壳建模方案、连接理想化、梁偏置与螺栓连接 |
| 大型钢结构案例 | 10 | 台架的梁/壳建模与强度刚度分析 |
| 工程机械案例 | 11 | 挖掘机动臂/斗杆工作装置、静力学、运动/连接关系 |
| 机构案例 | 12—13 | 剪叉升降机的运动副、几何清理、壳建模与连接细化 |

## 与个人论文/CAE 作品集的关系

课程重点是**工程几何抽象 → 网格 → 连接与边界 → 求解后处理 → 工程判定**。它可以支撑风电塔架等工程结构的建模方法学习，但**不能证明用户已完成光伏支架、台架、挖掘机或剪叉升降机的模型计算**。只有后续保存了本人可重现的模型、计算文件、核验数据和结果，才应向 [CAE 作品集](../../README.md)登记个人项目。

## 归档规则

- 自第 02 课起：**一课一个独立 `.txt` 文件**，文件名同时注明课次和核心主题，不把多堂课合并。
- 每份文件仅包含该次上传的原始转写（统一换行符以便 GitHub 浏览），**不删改讲课文字**。原文中的错字、误识别名称、口语内容均保留。
- 资料完整性以本次收到的文本为准。**无法仅凭这六份转写确认录像是否从头到尾完整。** 如后续补传片段，另行核对追加。
- 老师演示过的模型、网格、材料和仿真结果，**并未随本次六份文本上传**。不能把课堂演示登记为个人已完成的 CAD/CAE 作品。
- 课程里的软件版本、行业评价、经验阈值和仿真结论须使用软件文档及实际工况核实后，再用于技术报告。
- 对第三方课程资料的公开传播应遵守原作者的版权、许可及课程使用条款。本 GitHub 仓库目前为公开仓库。

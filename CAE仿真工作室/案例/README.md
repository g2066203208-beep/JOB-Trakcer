**注意：** 研究记录表示此前有分析背景与数据记录，不代表本目录中存在可运行模型，更不是已重新校核。默认不得作为“完成/通过验证”的宣传材料。

## 新建案例步骤

1. 分配唯一 ID，说明任务目的、对照基准与预期输出。
2. 新建案例目录，将模板填写完整，记录软件版本和来源。
3. 保存源文件、脚本/操作记录、计算日志和结果原始数据。
4. 给云图/曲线增加单位、坐标、图例、工况、版本与来源。
5. 基于真实复核材料更新案例状态，并同步 `../data.js`。
6. 若仅做简历展示，导出不涉密的小体积结果图与摘要即可，不将无许可证模型上传公共仓库。

# CAE Studio｜仿真作品集

这是一个**展示真实 CAE 计算成果的网页**，而非学习任务打卡页。页面设计重点是作品封面、实际计算结果、模型和报告。原先装饰性的虚构塔筒和网格示意图已移除。

## 作品集网页

[打开 CAE Studio](https://g2066203208-beep.github.io/JOB-Trakcer/CAE仿真工作室/)

代码入口：index.html / styles.css / app.js / data.js / viewer3d.js。采用原仓库 GitHub Pages 静态部署方式。

## Abaqus 与 ANSYS 可交互场云图（新增）

现在可导入 `*.cae.json`（`cae-field-v1`）并在网页上查看真实的**表面节点应力云图、位移云图、按步播放、变形倍率、网格和数值查询**。这不同于仅展示静态图片。Abaqus `.odb` 与 ANSYS `.rst` 必须经过软件环境中的导出工具转换，**不支持直接将这两种原生结果文件拖入浏览器**。

- [Abaqus/ANSYS 导出和交互查看说明](./导出工具/README.md)
- [ANSYS DPF RST 导出脚本](./导出工具/ansys_rst_export.py)
- [Abaqus ODB 导出脚本](./导出工具/abaqus_odb_export.py)

**软件条件和限制：** 两个脚本尚未在你本机真实求解结果上验证。ANSYS 需要 PyDPF-Core、PyVista 和兼容的 DPF 环境；Abaqus 需要自带 `odbAccess`。导出的是有限元外表面的节点场；节点应力平均、单元阶次和积分点的显示方式可能与原软件默认云图不同，必须对照原始结果核验。

## 已实现的能力

| 类型 | 直接可预览的格式 | 展示方式 |
|---|---|---|
| 云图、网格图、结果对比 | PNG / JPG / WEBP / GIF / BMP | 缩略图、原图放大、同项目两张图片叠加滑块对比 |
| 求解动画 | MP4 / WEBM | 原生播放器 |
| 时程与其他数值曲线 | CSV / TSV / TXT | 真实数据画线，切换 X/Y 数值列 |
| 仿真模型 | STL / OBJ / GLB（优选）/ 单文件 GLTF | Three.js 网页旋转、缩放和平移 |
| 技术报告 | PDF | 浏览器内嵌查看或保存源文件 |

**不支持网页直接解析 Abaqus ODB、ANSYS RST/RTH、LS-DYNA D3PLOT、Nastran OP2**。这些求解器专有二进制格式必须从对应软件导出支持的格式。对云图建议导出高清 PNG；对动画建议 MP4/WebM；对曲线建议带完整列名与单位的 CSV；对三维几何建议 GLB、STL 或 OBJ。GLB 适合打包网格和材质，STL/OBJ 主要保留几何；**几何模型查看器不等于完整求解结果查看器**，不会自动解析应力场和变形结果。

三维预览依赖在线加载 Three.js 模块；离线或 CDN 被限制时可正常查看图片、动画、PDF 和 CSV，但三维预览可能不可用。

## 立即使用

1. 打开工作室网站 → 「＋ 导入结果」。
2. 选择项目、软件、结果名称和工况/单位，拖入本机文件（支持批量）。
3. 在「结果浏览」里筛选项目、文件类型，查看原图、曲线、视频、报告或可旋转的三维模型。
4. 图片对比要求同项目至少两张图片。**需要人为保证视角、色标、物理量和工况可比**，页面不会自动对齐/匹配色标。
5. 新项目通过「＋ 创建项目」在当前浏览器中新建。

本机导入使用 **IndexedDB**，只保存在当前浏览器；换设备、清理浏览器网站数据或使用隐私模式可能丢失。网页**不具备 GitHub 写入授权**，所以本地导入的结果不会自动同步到仓库或被其他访问者看到；存储容量由浏览器决定。单文件预览上限 150 MB，巨大模型/结果应先做轻量化导出。

## 发布为所有访客可见的真实作品

把经过核对且允许公开的模型、图片、报告、动画和 CSV 放到仓库路径，例如：

    CAE仿真工作室/成果/CAE-001/
      cover.png
      mode-01.png
      root-stress.png
      twr-top-time-history.csv
      result-video.mp4
      model.glb
      technical-report.pdf
      README.md

然后在 data.js 的 CAE_SEED.assets 数组中增添**对应记录**。示例（仅示范字段，仓库当前并不存在这些文件）：

~~~js
{
  id:"CASE001-MODE01",
  projectId:"CAE-001",
  title:"一阶弯曲模态",
  name:"mode-01.png",
  kind:"image",
  software:"Abaqus",
  notes:"工况及单位待填",
  src:"./成果/CAE-001/mode-01.png",
  createdAt:"2026-10-10T00:00:00.000Z"
}
~~~

说明：kind 取 image / video / csv / pdf / model。每个素材都应能从 GitHub 文件路径打开，不要给尚未上传的素材添加占位路径或使用未经授权的第三方结果截图。

## 内容管理

- data.js：公开案例和素材索引；初始只有案例背景，没有虚构截图。
- 案例/：案例工作过程与验证文件。
- 成果/：对外公开的原始输出、截图、报告、模型、来源登记。
- 模板/：标准案例记录模板。
- 学习路线.md：保留学习资料，但不再占据作品集首页。

所有研究数据在正式公开前应核对版本、载荷、单位、结果来源，避免把先前的研究摘要当成已验证的模型计算输出。**其他人的研究不得当作自己的项目成果。**

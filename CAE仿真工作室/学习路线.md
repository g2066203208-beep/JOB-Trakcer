# CAE 工程仿真学习路线｜v1.0

目标：从已有土木/结构动力学分析经验出发，逐步积累适用于工业结构 CAE 岗位的通用方法；每一阶段必须产生**可重复的算例+校核报告**。

| 阶段 | 内容 | 应交付的验收材料 |
|---|---|---|
| 0 有限元方法 | 结构力学、离散、单元类型、边界约束、线性方程、误差 | 悬臂梁解析解比较、网格收敛表 |
| 1 Abaqus | 几何、装配、材料、网格、静力、模态、非线性、后处理 | INP/CAE、ODB 索引、位移应力表、计算日志 |
| 2 LS-DYNA | 显式积分、接触、材料、本构、时间步、能量检验 | K 文件、能量与时间步图、参考对照 |
| 3 迁移技能 | SolidWorks/CAD 前处理、ANSYS 对照、MATLAB 数据、振动疲劳 | 两软件一致性对比、疲劳分析小案例 |
| 4 工业交付 | 工况矩阵、敏感性、质量审查、自动化记录、报告 | 完整案例证据包及对外展示页 |

## 基础技能清单

**理论：** 单位制、应力/应变、材料线弹性/塑性、几何非线性、模态/频响、动力响应、稳定时间步、数值收敛与误差传播。

**建模：** 几何简化/理想化、梁/壳/实体单元选型、截面与连接、约束、载荷传递、质量与惯量检查、网格质量。

**求解：** 静力/隐式/显式的选择、求解控制、收敛警告、能量平衡、接触稳定性、边界反力与守恒。

**后处理：** 变形/应力/应变、模态、时程、PSD、疲劳指标、截面曲线；不得仅凭单张漂亮云图得出工程结论。

**验证：** 解析解、标准算例、试验/文献对照、网格与参数敏感性、模型局限和不确定性。

## 优先制作的 5 套跨行业练习

1. **悬臂梁/支架静力**：挠度理论解，逐级网格，最大位移与应力收敛。
2. **带孔板应力集中**：边界与载荷、局部网格优化、Kt 估算与误差分析。
3. **简化支架模态/振动**：质量和刚度校核、模态频率、参与质量、载荷频带。
4. **接触压装/螺栓连接**：接触参数、收敛控制、反力检查、网格敏感性。
5. **公开显式冲击基准**：时间步、接触能量、动能与内能、和参考解比较。

以上是**待开展的学习任务**，非已完成成果。

## CAE 案例报告的验收问题

- 为什么选择此单元、材料模型和求解器？
- 几何简化是否影响关注的结果？
- 荷载、约束、接触条件的证据是什么？
- 关键曲线、误差和网格收敛能否重算？
- 是否记录异常警告、求解失败和修复过程？
- 是否说明适用范围、无法验证的部分及版本依赖？

## 对应职业能力（学习目标，而非现有能力声明）

- **结构 CAE**：静力、强度、刚度、稳定性、接触、优化。
- **动力 CAE**：模态、瞬态、频响、随机振动、疲劳。
- **显式碰撞/冲击**：材料/接触、本构、时间积分、能量质量平衡。
- **新能源装备**：载荷生成、机组/塔架动力响应、疲劳评价。
- **仿真质量/标准评估**：需求解读、验证矩阵、结果复核、工程报告。

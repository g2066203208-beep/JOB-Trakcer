# Character Skeleton Studio

A zero-dependency 2D skeleton editor for the measured paper-character proportions.

## Reference geometry

- Head diameter: 224 px
- Neck: 36 × 34 px
- Shoulder width: 120 px
- Torso height: 276 px
- Upper arm: 139 px
- Forearm: 145 px
- Arm width: 34 px
- Elbow joint diameter: 48 px
- Thigh: 216 px
- Shin: 242 px
- Leg width: 80 px
- Knee joint diameter: 70 px
- Hand box: 100 × 104 px
- Foot box: 74 × 91 px

## Interaction

Every blue joint handle is draggable with Pointer Events, so the same editor works with mouse, pen and touch. Bone rectangles rotate and stretch between their connected joints in real time.

This first version intentionally has no IK constraints. It is a direct bone-layout test bed.

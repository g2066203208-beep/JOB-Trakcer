# UniJob AI · 大学生就业智能平台

从 JOB-Trakcer 升级而来，目标是建设面向所有专业大学生的就业信息、岗位管理和智能匹配平台。

## 当前基础功能
- 公开浏览企业与岗位
- 岗位搜索与筛选
- 企业库
- 投递状态管理
- 用户独立保存申请记录与备注
- GitHub Pages 发布

## UniJob AI 升级方向
详见 `UNIJOB_AI_ROADMAP.md`

## 平台规划

### 就业数据库
- 企业库
- 岗位库
- 专业标签库
- 技能标签库

### 用户画像
- 学校
- 学历
- 专业
- 技能
- 求职方向
- 城市偏好

### AI功能
- 岗位匹配
- 简历分析
- 面试辅助
- 职业路径规划

## 技术方向
- 前端：逐步模块化重构
- 后端：Supabase/PostgreSQL
- AI：岗位解析、简历理解、推荐系统

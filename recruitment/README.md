## 投递核验说明

1. **海口办公室 ≠ 海口招人**：如广东省建院有海口办公地点，但岗位城市与名额仍须在其网申系统查证。
2. **总部深圳 ≠ 岗位固定深圳**：中建、中铁项目组织可能跨地调配；明确提问签约主体、首年驻地、项目调动条款和待遇。
3. **报名时间缺失不猜测**：本表只录明示期限；高校网页“过期时间”不等于用人单位最终网申截止日。
4. **海南华电2027第一批未列入推荐**：海南公司公开的本批专业仅电气、计算机，不可误荐土木工程生。
5. **不杜撰个人申请进度**：当前全部标为“未查已投”，后续对照实际投递记录改成已投/测评/笔试/面试/拒绝/撤销等。
6. **优先避免需要随项目全国调动的施工岗位**：此类列为“谨慎”而非高优先。

- **“2027已核实”**：有2027招聘公告或岗位材料，但不代表岗位仍有名额；重要条件务必登陆官网确认。

- **深圳国资候选企业**：政府官方列表提供微信“深圳国资招聘”公众号 / “菁英聚鹏城”小程序路径，不存在已验证的每家独立2027直投网址；候选企业附官方指引页而非造假网址。

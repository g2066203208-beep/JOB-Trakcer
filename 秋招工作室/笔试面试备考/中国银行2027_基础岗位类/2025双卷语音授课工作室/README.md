## 如何交给语音GPT

上传**相应PDF原件和对应的演讲稿Markdown**，对语音GPT说：

> 你现在是中国银行校招笔试的耐心老师。严格根据我给你的PDF和演讲稿授课。从当前章节第一题讲到最后一题，不要中途停下来问我是否继续。先念清题目和选项，再报告“原卷参考答案”，然后用通俗中文逐步讲清理由、排除方法、公式、英语翻译和考点；遇到原卷错题或存疑答案，请明确区分参考答案与正确知识；看不清题干、图形、表格时必须查看PDF画面，不能凭空补写。每讲完一小组题目简短复盘，然后自动继续下一组。

## 质量要求

1. 原题来自用户PDF；不要混卷、漏卷或自造题。
2. **原卷的答案与教师独立判断分开写**。如果原卷答案可疑，应标注“原卷答案存疑”。
3. 语音讲解不是只读答案：必须讲计算理由、逻辑关键词、英语语法或金融概念。
4. 对难以纯文字朗读的题，给语音GPT明确的原PDF页码。
5. 文档版本会写明已实质完成的范围；**模板或识别稿不冒充已完成精讲**。

## 2. 核心公式与答题逻辑

### 2.1 气动
- 来流可用功率：P_w=0.5ρAU^3；轴功率 P=0.5ρAU^3 Cp(λ,β)；电功率还应计入实际传动/发电效率，具体效率位置不得混淆。
- 叶尖速比 λ=ΩR/U；功率系数 Cp=P/(0.5ρAU³)；推力 T=0.5ρAU² Ct；在其他系数及条件相同下，功率近似随U³、推力近似随U²变化，**机组控制变化时不能机械套用这个比例**。
- 叶素法相对入流角 φ≈atan[(U(1-a))/(Ωr(1+a′))]（理想轴向、忽略复杂几何与局部速度扰动的简化写法）；攻角 α=φ-(扭角+桨距角)（遵循同一正向约定）。
- 单位叶片展向长度升力 L′=0.5ρW²cCl，阻力 D′=0.5ρW²cCd；叶素法把升阻力分解为转子法向力与切向力，后者积分产生转矩。
- BEM = 叶素的局部气动力与动量理论的轴向/切向诱导耦合迭代；需考虑叶尖/叶根损失、高诱导区修正、偏航斜尾流及可能的动态入流和动态失速。**不能说简单将风压乘面积就是OpenFAST整机载荷**。
- AeroDyn在OpenFAST v3.5.3的稳态BEM、Glauert/Buhl、高诱导区、Prandtl损失、Pitt-Peters斜尾流等技术见 https://openfast.readthedocs.io/en/v3.5.3/source/user/aerodyn/introduction.html 。

### 2.2 动力与频域
- 线性结构：Mü + C u̇ + K u=F(t)；模态无阻尼自由振动 (K-ω²M)φ=0，f=ω/(2π)。实际风机载荷可为非线性、时变、耦合。
- 转速n(rpm)时 f1P=n/60(Hz)，三叶片 f3P=3n/60；1P为转子转动一次频率，3P是典型叶片通过频率。不同测点、非对称和边界条件下可能有不同阶次，**不是说只存在1P/3P**。
- FFT显示频率分量；PSD显示单位频率带宽功率/方差密度。均匀采样时Nyquist上限 f_s/2，频率分辨率约 Δf=1/T，窗函数和平均、去趋势会影响谱估计。
- Campbell：把模态频率与转速阶次激励曲线放在同一转速轴，辨识潜在交叉；交叉**不等于必然共振失效**，需结合阻尼、模态参与、激励强度与工况验证。

### 2.3 风场与认证
- NTM=正常湍流模型，ETM=极端湍流模型；TurbSim生成时间/空间相关湍流风场，不能把“随机种子变了”误当“风场模型变了”。
- 极限载荷 ULS：关注各DLC的关键部件载荷极值、组合与安全系数；疲劳 FLS：关注长期变幅循环、发生概率、材料S-N斜率、累计损伤。
- 典型DLC：1.2通常对应正常发电疲劳场景；1.3可用于正常发电极端湍流；1.4为极端阵风/风向变化类瞬态；具体定义、仿真时长、风况、偏航/故障组合和系数须按**明确采用的现行IEC版本正文**核对，不背旧版表格冒充全部现行规范。
- **现行IEC参考**：IEC 61400-1:2019+AMD1:2025（IEC2025-12-18整合版）；还应关注 DNV-ST-0437(2024-05)风况/载荷及认证工作流程。
  - https://webstore.iec.ch/en/publication/111042
  - https://www.dnv.com/energy/standards-guidelines/dnv-st-0437-loads-and-site-conditions-for-wind-turbines/
- SSDA/SDA（场址适应性评估）：将实际场址风速分布、湍流、风切变、入流角、尾流、极端风和其他环境条件与机组设计范围/载荷比较，不等于简单换算风速，不是凭一个DLC算例就取得认证。
  - https://www.dnv.com/services/renewables-certification/site-specific-design-assessment-of-wind-turbines/

### 2.4 雨流、疲劳与DEL
- Rainflow：把不规则载荷时程分解为幅值/均值不同的完整或半循环，再形成循环次数与载荷范围分布。不同实现对剩余半循环、边界及计数约定有差别。
- Miner损伤 D=Σ(n_i/N_i)；在合适材料S-N参数与评估条件下估算累计疲劳。
- 固定参考循环次数N_eq、Wöhler指数m：**DEL=[Σ(n_i ΔL_i^m)/N_eq]^(1/m)**。这里 ΔL_i须明确是载荷**范围(range)**，若使用幅值(amplitude)应转换，不可混用。
- DEL **不是**实际疲劳寿命，也不是直接可以作为载荷极值输入的最大载荷；跨模型/工况比较必须同一m、N_eq、载荷单位、预处理、计数约定。
- 参阅OpenFAST官方Toolbox：https://github.com/OpenFAST/openfast_toolbox/blob/main/openfast_toolbox/tools/fatigue.py 。

### 2.5 OpenFAST模块思路
- TurbSim（独立前处理器）构造风场；InflowWind读入流；AeroDyn算气动载荷；ElastoDyn算主要结构自由度与运动；ServoDyn控制与执行机构/接口；必要时BeamDyn高保真叶片；HydroDyn/SeaState等海上水动力模型。
- 典型闭环：风→相对流速/叶素气动力→叶片、RNA、塔架动力响应→传感/控制输入→变桨/发电机力矩改变→反过来改变气动与结构载荷。
- 整机负载要输出固定的通道、单位、坐标系和采样间隔。塔底弯矩TwrBsMyt等通道**不能在未知轴定义时直接当作某方向绝对弯矩**。
- 数据后处理：检查初始瞬态、NaN/丢步、风速/转速/变桨/功率、载荷极值同一时刻联动、频谱、雨流、疲劳和多个种子离散性，按统一工况台账存档。

## 3. 原创计算模拟题（附标准解）

**题1：叶尖速比**。叶片半径R=80 m，转速n=11 rpm，来流U=10 m/s。求λ。
- Ω=2πn/60=1.1519rad/s；λ=ΩR/U≈**9.22**。易错：rpm未转rad/s。

**题2：功率**。ρ=1.225kg/m³，R=80m，U=10m/s，Cp=0.45，额外效率η=0.95，电功率？
- P_e=0.5×1.225×π×80²×10³×0.45×0.95≈**5.26MW**。已假设两种系数常数，实际随工况改变。

**题3：1P/3P**。转子转速9rpm；答：1P=9/60=**0.15Hz**，3P=**0.45Hz**。不能将三叶片3P误认为3Hz。

**题4：简化频率**。k=4×10^6N/m，m=1×10^7kg，单自由度无阻尼频率？
- f=(1/2π)√(k/m)=**0.1007Hz**。实际塔架多自由度+RNA/土体边界需模态求解，不能用此简化替代实际设计。

**题5：叶素攻角**。局部入流角φ=12°，几何扭角3°，桨距角2°（相同正向约定）；α=12-3-2=**7°**。

**题6：疲劳等效载荷**。100个载荷范围100kN·m循环、10个载荷范围200kN·m循环，m=4，N_eq=1000，求DEL。
- DEL=[(100×100^4 +10×200^4)/1000]^(1/4)=**71.4kN·m**。区分范围与幅值；不能拿它与瞬时最大200kN·m相等。

**题7：Miner**。两组循环n1=30000,N1=1000000；n2=2000,N2=100000。D=0.03+0.02=**0.05**。这只是模型预测损伤占比，含S-N、平均应力、修正等前提。

**题8：FFT**。20Hz采样，稳定分析时段T=600s。Nyquist=**10Hz**；理想频率栅格间距≈**0.001667Hz**；能够覆盖0.45Hz 3P。需防混叠、去趋势、窗函数、解释统计稳定性。

**题9：模态偏差**。参考频率0.13610Hz，计算0.13718Hz；相对参考偏差=(0.13718-0.13610)/0.13610×100%=**约0.79%**。代表模型这一频率指标接近，不能据此证明全部静强度/疲劳都准确。

**题10：BEM定性**。同一局部相对流速W下弦长c增加20%，其他Cl/ρ不变，单位叶片展向升力增加**20%**；但实际c变化会使诱导、结构及工作点变化，不宜假定整机载荷仍线性。

**题11：风速变化**。若U从8m/s→10m/s且Cp不变，风能功率比=(10/8)^3=**1.953125**；假定Ct不变，推力比=(10/8)^2=**1.5625**。跨额定风速不能直接这样套。

**题12：振动减载**。在同一单位下，比值f_exc/f_n=1附近风险高，但仅凭接近频率不能判定载荷超限，需看阻尼、幅值、模态参与以及结构和控制耦合。不得机械断言“离1P越远就一定安全”，还应检查3P及其他激励。

## 4. 专业面试问题及可直接讲述的答案要点

**Q1. 风机整机载荷是怎么来的？**
答：时变三维入流经气动模型产生叶片分布力及力矩，施加于柔性叶片、转子、传动链和塔架；结构位移/速度改变相对入流；发电机扭矩、变桨和偏航反馈又改变气动载荷。通过时域耦合仿真得到塔底弯矩、叶根弯矩、轮毂和传动链载荷，再做极值、统计、PSD、疲劳和DLC筛选。

**Q2. BEM的局限？**
答：稳态轴对称动量理论基础上构建的工程模型，对大偏航、强非定常、复杂尾流、叶片高柔性变形的准确性依赖修正与模型假设；可采用动态入流/失速、叶尖损失、高诱导修正，特殊需要下结合自由涡尾迹、CFD和测试验证。

**Q3. NTM与ETM区别？**
答：前者评价正常湍流统计输入，后者代表极端湍流条件，通常关心不同载荷风险；不是只调换随机种子。具体谱、湍流参数和IEC公式由适用版本确定。

**Q4. 风机为什么会出现1P/3P？**
答：1P是转子整周循环一次对应转频，3P是三叶片轮流通过相同方位产生的周期性激励；塔影、风切变、偏航与不对称等会引入多个阶次。以时域转速转换频率，结合FFT/PSD、Campbell判断接近哪些模态。

**Q5. 怎么检查OpenFAST结果可信？**
答：先核几何/质量/惯量/刚度/模态/控制器版本/坐标系，再做稳态功率曲线与转速桨距响应合理性，检查随机风场、时间步长、启动段、异常通道和物理平衡；与论文基准、独立结构模型或实测数据对比；变化参数时保持相同统计口径做敏感性检验。

**Q6. DEL的工程意义？**
答：用m次损伤等效将一段不规则变幅荷载转换成在指定N_eq下等损伤的恒定载荷范围，便于跨工况和设计方案比较。依赖S-N斜率和范围计数，不等于极限载荷、损伤值或寿命本身。

**Q7. 为什么选6个随机种子、后600秒？**
答：每风况采用多个随机种子以体现湍流 realizations 的离散性；总时长700秒，按项目约定去掉起始100秒并统计后600秒，以尽量排除初始化暂态。**这只是本研究的设计**，是否满足规范的每个DLC时长/种子及认证要求必须重新对照，不能称为IEC全套已验收。

**Q8. 你的36组工况是否能用来认证？**
答：不能直接这么说。它们是本研究对特定NTM/ETM及代表风速/种子的分析矩阵，已完成时域统计和DEL；认证还需完整DLC、风况概率、停机/故障/极端事件、各类安全系数、设计寿命及测试验证等。

**Q9. Abaqus与OpenFAST如何分工？**
答：OpenFAST侧重整机气动-结构-控制耦合载荷时程；Abaqus侧重混合塔架的更细致结构有限元响应/模态/局部应力分析。将OpenFAST得到的载荷按规定接口、参考点、坐标系映射到结构模型，再验证总力、总矩与时钟一致，避免简单说“Abaqus算了全部真实气动”。

**Q10. 为什么RNA需要简化、如何验证？**
答：针对塔架整体动力学可用质量、质心和转动惯量的等效RNA或主控模态相关的降阶方案，而机舱局部强度则需要更详细部件模型。用户项目已做RNA质量一致性校核，约0.004%差异；质量对上并不能代表惯量、连接刚度、模态全正确，需要逐项核验。

**Q11. 模态0.79%偏差是否就足够证明模型可靠？**
答：只能证明相关首阶频率与对标对象很接近。仍需对质量、EI分布、边界刚度、振型、其他模态、静载响应及网格敏感性做独立验证，不能外推到所有疲劳强度。

**Q12. 降载是不是增加变桨就够？**
答：不是。降载可来自独立变桨、扭矩控制、滤波/阻尼控制、运行区间调整、偏航优化等；必须权衡发电量、执行器动作、结构疲劳、极限载荷与闭环稳定性，在多DLC与功率曲线上验证，不简单追求一个通道最小。

**Q13. 如果仿真与实测差20%，如何排查？**
答：先确认同一时间段/气象工况、标定与传感器精度、坐标系单位采样率，再查机组转速、变桨、偏航和状态机，入流测量代表性、风切变与湍流、基础边界、阻尼、结构质量刚度、气动数据。将差值分解为稳态偏差/频域峰偏差/极值或疲劳偏差，逐一做敏感性和复现实验，更新模型形成闭环；不是先随意调阻尼凑结果。

**Q14. Bladed没用过怎么办？**
答：如实答“目前实际使用OpenFAST v3.5.3为主，掌握输入模型、气动-结构-控制链路、工况生成和时序后处理；了解到Bladed同样面向整机气弹载荷，但软件格式和求解模型有差异，目前尚无独立Bladed工程项目经验，可依托现有理论快速学习。”不要说精通Bladed。

**Q15. 你会Python或Matlab编程吗？**
答：不能谎称会Python。准确说“通过全国计算机二级C语言，了解基础程序设计；项目仿真和数据流程以OpenFAST、Excel等为主，借助大模型/Agent配置工具并辅助生成/调试脚本；我本人会核对输入、输出和物理合理性，独立复杂工程代码开发还在学习。”这项是JD明确短板，应补基础概念。

**Q16. 你是土木专业为什么适合整机载荷？**
答：结构动力学、模态/刚度/疲劳与模型验证是通用力学基础，而你的课题延伸到气动弹性、风机控制、时频域和整机后处理。优势是载荷到塔架响应的完整理解，不夸口已具备企业级气动算法开发能力；说明会针对风机整机控制、Bladed和编程补强。

**Q17. 现场某台风机塔底载荷突然升高？**
答：确定是极值还是均方/DEL增长，核查风速、湍流、尾流、偏航、转速、桨距、故障、传感器漂移及对应事件时间，复现同条件仿真，对照频域峰值并区分激励加剧还是固有频率/阻尼变化，然后针对控制/结构/测量给出候选修正方案，验证后实施。

**Q18. 最大技术难点是什么？**

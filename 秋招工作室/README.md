## 数据准确性规则

0. **聊天中确认的就业信息要同步维护到本工作室**：企业、岗位、地点、投递状态、截止时间、测评/笔试/面试节点等；未确认内容不得猜测。

1. 用户明确说“投了” → 企业层面记为 **已投递**。
2. 公开招聘页能确认的 → 记录“公开岗位池/岗位要求”。
3. 公开链接不能证明用户实际勾选了哪一岗 → **不猜**，标“待核对”。
4. 有唯一岗位ID但标题无法公开解析 → 保留岗位ID，等待个人投递记录核验。
5. 拿到“我的投递”截图/邮件后，立即把实际岗位名称写死。

## 状态流水线

正在网申 → 已投递 → 测评 → 笔试 → 一面 → 二面/终面 → HR → Offer

同时允许：拒绝 / 主动结束 / 无反馈。

## 使用原则

1. A级岗位：每天检查并做针对准备。
2. B级岗位：有流程推进时升级。
3. C级岗位：只保留，不占核心准备时间。
4. 不以“投递数量”作为主要指标，看“投递→笔试→面试→Offer”的转化。
5. 每次面试后24小时内写复盘。
6. 涉及补贴、档案、落户、毕业手续等政策性事项，办理前必须回官方渠道复核最新版本。

# 秋招工作室

目标：把“投了什么”变成“每个岗位下一步该准备什么”。

## 当前数据状态

旧版 JOB-Trakcer 的个人投递状态曾保存在浏览器 LocalStorage / Supabase 的 `user_applications` 中，而不是 Git 提交文件里。
因此仅凭当前仓库历史，**不能可靠还原你的完整已投企业与岗位清单**，不能猜。

当前工作室先建立完整结构；你把旧投递截图、导出记录或企业+岗位名单给我后，我会把真实记录固化进仓库。

## 每个岗位必须记录

- 企业
- 岗位
- 方向/赛道
- 地点
- 投递日期
- 当前状态
- 截止/测评/笔试/面试时间
- 简历版本
- JD关键词
- 关键能力
- 个人匹配证据
- 能力缺口
- 企业研究
- 笔试准备
- 面试准备
- 项目故事
- 下一步动作
- 优先级

## 状态流水线

已投递 → 测评 → 笔试 → 一面 → 二面/终面 → HR → Offer

同时允许：拒绝 / 主动结束 / 无反馈。

## 使用原则

1. A级岗位：每天检查并做针对准备。
2. B级岗位：有流程推进时升级。
3. C级岗位：只保留，不占核心准备时间。
4. 不以“投递数量”作为主要指标，看“投递→笔试→面试→Offer”的转化。
5. 每次面试后24小时内写复盘。

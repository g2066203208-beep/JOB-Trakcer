## 公考拆分

- 行测：每天 2 小时，按资料分析→判断推理→数量关系→言语理解→混合限时→整套模拟→错题复盘循环。
- 申论：每天 1 小时，继续以白鹭 DAY60 为主；不跳步骤，不把自创表达当“标准答案”。

## 高效规则

1. 08:30 前不开短视频/社交媒体。
2. 2 小时块采用 50+10+50+10；1 小时块采用 45+15。
3. 每个模块只统计“产出”，不统计“坐了多久”。
4. 错题必须记录错因：知识不会 / 审题错 / 计算错 / 时间不够 / 犹豫改错。
5. 秋招投递必须记录岗位、版本、日期、状态；禁止无脑海投。
6. 论文每天必须有“可见进度”：新增字数、完成图表、实验结果或文献笔记。
7. 周日不盲目开新坑，以复盘和补薄弱项为主。

## DAY03 后的固定教学基准

完整规则见：[白鹭教学基准](./白鹭教学基准.md)

核心顺序：

**审题 → 字数换行数/预判句数 → 对比材料段数与预判句数 → 阅读时运用关键词/逻辑方法找点 → 必要时用补救办法 → 先列全要点 → 就近合并 → 前置提炼 → 作答**

### 审题
- 明确阅读范围
- 明确作答对象/题型
- 看具体要求
- 字数换算为行数，再预判句数

### 找点
- 先找全，后合并
- 用户先圈，老师只纠正“该不该圈 / 漏没漏 / 圈多没多”
- 关键词阅读法和逻辑阅读法是**找点时直接使用的阅读技法**，不是圈完以后必须额外闯的两个固定关卡
- **不允许跳过圈材料直接给概括**

### 关键词阅读
八类敏感信号：
1. 首尾位置（尤其尾句）
2. 最高级
3. 递进词
4. 转折词
5. 并列词
6. 结论词
7. 引出观点词
8. 特殊标点

### 逻辑阅读
- 总分：**留总不留分**
- 并列：**全留或全扔**
- 关键词重复：通常要合并，并找总结句

### 找点补救
- 主题词定位：有问有答即是答案
- 高频词圈定：一段出现2次及以上就要敏感
- 长句首尾相接：优先保住敏感位置

### 加工
- **分条 = 就近合并**
- **条理 = 分条 + 前置提炼**
- 前置提炼尽量4/6/8字
- 准确：材料原词优先
- 全面：预判句数范围内有效词尽量多

## 教学纪律

1. 用户先做，助手后纠偏。
2. 每一步只做当前步骤，不一次把后面答案全喂出来。
3. 不把助手自己的概括称为“白鹭标准答案”。
4. 如果白鹭原始答案未核到，要明确说来源性质。
5. 当前这份 DAY3 全文是**理论课全文**，并不包含“小雷题”的标准答案；两者不能混为一谈。

## 一、第一轮圈原文：今天真正学会了什么

### 1. 先找“动作”，但不要只盯动作

一开始用“问题 / 痛点 → 动作 → 目的 / 效果”帮助找信息。

例如：
- “将人工智能引入水稻种植阶段”
- “通过高科技为传统农业增效”
- “机器鸭代替人巡田、除草”
- “效率提高、成本降低”
- “物联网、智能机器监测采集”
- “建模、大数据分析、人工智能训练、图像识别”
- “实现无人化、智能化管理”

今天纠正：
> **有动作，不等于一定是最终答案。**

### 2. 长句不能只圈句首和句尾

第三段曾漏掉中间动作。以后看到长句要顺着动词找：

**采集 → 分析 → 建模 → 识别 → 指导 → 实现智能管理**

提醒：
> 看到长句，问自己：**中间还有没有新的动作？**

### 3. 一段里先全圈，再找“大动作”

第五段最典型：

具体动作：
- 一产：种植标准化、人工智能化
- 二产：加工
- 三产：休闲观光、户外活动、民宿、乡村艺术

段尾总括：
- “一二三产业高度融合发展”
- “打造新型全产业链模式”

今天学会：
> **先圈所有动作，再看后面有没有一句能把前面全包住。**

如果有，最终答题优先用这个“大动作 / 总括词”。

### 4. 判断是不是答案，要重新回题

第六段曾困惑“培养知识型、技术型新型农民”是不是青年创业者应该做的。

今天形成的判断：
> 问自己：**这句话能不能转成‘新时代青年创业者应该……’？**

但按白鹭讲解，最终不是机械抓“培养”二字，而是看整段反复出现：
- 27岁
- 青年
- 青春
- 年轻人
- 返乡青年

从整段主题提炼为：
**打造年轻人队伍 / 吸引青年人才。**

## 二、白鹭式合并：18+个圈画点，最后压成4大点

### ① 运用高新技术

原文信息组：
- 人工智能
- 高新技术 / 高科技
- 机器代替人工
- 提高效率、降低成本
- 物联网
- 大数据
- 无人化、智能化管理

合并原因：
这些都属于“技术”这一类。

前置提炼：
**运用高新技术。**

最终分写：
- 人工智能 → 提高效率
- 机器代替人工 → 降低成本
- 大数据 → 无人化、智能化管理

### ② 产业融合发展

原文信息组：
- 引入旅游、文化、艺术等多元化产业
- 打造共享农场、田园综合体
- 挖掘稻米文化
- 开发衍生产品
- 一产、二产、三产
- 一二三产业高度融合
- 新型全产业链模式
- 更多发展机遇

段尾本身给出总括词，因此提炼：
**产业融合发展。**

### ③ 打造年轻人队伍

原文信息组：
- 平均年龄27岁
- 知识型、技术型“新型农民”
- 青年人的青春舞台
- 很难吸引年轻人
- 让农民成为令人羡慕的职业
- 示范和带动更多返乡青年扎根农村

白鹭式判断：
不是只抓“培养”动作，而是看整段高频主题“青年 / 年轻人”。

前置提炼：
**打造年轻人队伍。**

### ④ 具备社会担当

原文信息组：
- 服务百姓、让群众吃到更高品质大米
- 乡村振兴
- 战略的实践者和受益者
- “新时代的创业者，一定要有社会担当”
- 做对国家和社会发展有意义的事情

这里材料已经直接给出总结词：
**具备社会担当。**

## 三、我今天自己写出来的最终答案

**一是运用高新技术。**运用人工智能等技术提高效率；通过机器代替人工降低成本；运用大数据技术实现无人化、智能化管理。

**二是产业融合发展。**引入旅游、文化、艺术等多元化产业，推动一二三产业高度融合，打造新型全产业链模式，开发衍生产品，创造更多发展机遇。

**三是打造年轻人队伍。**为青年搭建发展平台，吸引年轻人参与，增强从业年轻人的职业认同感。

**四是具备社会担当。**主动融入国家发展战略，投身乡村振兴等国家事业，做对国家和社会发展有意义的事情。

## 四、今天暴露的问题

1. **提炼太早**：看到“人工智能”就想马上得出答案，容易漏后面的效果和同类信息。
2. **过度具体**：曾写“赋能水稻种植”，题目问的是青年创业启示，应往普遍做法上提。
3. **擅自加词**：曾使用“具身智能”等材料没有的词。申论答案必须优先忠于材料。
4. **把所有动作都当答案**：动作只是找点入口，还需要看是否能回答题目、是否有更高一级总括。
5. **不会区分例子与上位概念**：旅游、文化、艺术是具体内容，“多元化产业 / 产业融合”才是上位概念。
6. **容易自己创造表达**：例如“青年军队”“凝聚农村生命力”，脱离材料且不符合白鹭提炼方式。
7. **忘记总分结构**：每个大点应该先写能统领后文的“总”，再写具体“分”。

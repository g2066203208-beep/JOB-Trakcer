# 白鹭申论教学基准

> 来源：用户提供的白鹭 DAY3 课程全文转录。  
> 作用：以后在本项目里教申论，优先遵守这套流程，不擅自换成别的机构套路。

## 核心顺序

**审题 → 字数换行数并预判句数 → 结合关键词阅读法/逻辑阅读法找点 → 找点困难时再用补救办法 → 要点先列全 → 就近合并 → 前置提炼 → 作答。**

> 说明：白鹭在 DAY3 里把“关键词阅读法”和“逻辑阅读法”讲成**找点时使用的阅读技法**，并没有规定必须在圈完材料后再依次做“关键词复核”“逻辑复核”。这两个步骤不能被我擅自改造成固定流水线。

## 1. 审题
必须先明确：
- 阅读范围
- 作答对象 / 题型
- 具体要求
- 字数换算成行数，再预判句数

## 2. 找点
先找全，后加工。

找点时直接运用白鹭讲的两套阅读技法：
- **关键词阅读法**：提高对采分点的敏感度、准确性；
- **逻辑阅读法**：识别总分/并列关系，提高找点准确率并节约阅读时间。

第一轮由用户自己勾画；老师只帮助判断：
- 该不该圈
- 有没有漏
- 有没有圈多
- 哪些材料原词必须保留

白鹭在课尾对初学者的要求是：**起码先把要点都勾画出来，一二三四列好，然后再考虑合并和前置提炼。**

## 3. 关键词阅读法
重点关注：
1. 首尾位置（尤其尾句）
2. 最高级
3. 递进词
4. 转折词
5. 并列词
6. 结论词
7. 引出观点词
8. 特殊标点

## 4. 逻辑阅读法
只抓实战最重要的两类：
- 总分：留总不留分
- 并列：全留或全扔

关键词重复通常意味着需要合并，并寻找总结句。

## 5. 补救
找点困难时：
- 主题词定位：有问有答即是答案
- 高频词圈定：一段2次及以上即可敏感
- 长句首尾相接：保住敏感位置关键词

## 6. 加工
- 分条 = 就近合并
- 条理 = 分条 + 前置提炼
- 前置提炼尽量4/6/8字以内
- 准确 = 原词优先，不擅自变词
- 全面 = 预判句数内有效词尽量多
- 内容具体 = 后半句补动作、效果、细节

## 7. 教学纪律
- 不跳过“圈材料”直接给概括
- 不把“关键词阅读”“逻辑阅读”擅自拆成白鹭没有规定的固定复核关卡
- 不把模型自己的提炼冒充“白鹭标准答案”
- 如果白鹭原始答案未核验，明确说来源性质
- 用户先做，老师再纠偏
- 要点先列全，再做就近合并和前置提炼

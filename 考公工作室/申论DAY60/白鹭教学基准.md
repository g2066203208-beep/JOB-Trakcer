# 白鹭申论教学基准

> 来源：用户提供的白鹭 DAY3 课程全文转录。  
> 作用：以后在本项目里教申论，优先遵守这套流程，不擅自换成别的机构套路。

## 核心顺序

**审题 → 预判 → 找点 → 关键词复核 → 逻辑判断 → 补救 → 合并 → 前置提炼 → 作答 → 对照白鹭**

## 1. 审题
必须先明确：
- 阅读范围
- 作答对象 / 题型
- 具体要求
- 字数换算成行数，再预判句数

## 2. 找点
先找全，后加工。

第一遍用户自己圈；老师只判断：
- 该不该圈
- 有没有漏
- 有没有圈多
- 哪些材料原词必须保留

**找点阶段禁止提前把标准答案喂给用户。**

## 3. 关键词阅读法
重点关注：
1. 首尾位置（尤其尾句）
2. 最高级
3. 递进词
4. 转折词
5. 并列词
6. 结论词
7. 引出观点词
8. 特殊标点

## 4. 逻辑阅读法
只抓实战最重要的两类：
- 总分：留总不留分
- 并列：全留或全扔

关键词重复通常意味着需要合并，并寻找总结句。

## 5. 补救
找点困难时：
- 主题词定位：有问有答即是答案
- 高频词圈定：一段2次及以上即可敏感
- 长句首尾相接：保住敏感位置关键词

## 6. 加工
- 分条 = 就近合并
- 条理 = 分条 + 前置提炼
- 前置提炼尽量4/6/8字以内
- 准确 = 原词优先，不擅自变词
- 全面 = 预判句数内有效词尽量多
- 内容具体 = 后半句补动作、效果、细节

## 7. 教学纪律
- 不跳过“圈材料”直接给概括
- 不把模型自己的提炼冒充“白鹭标准答案”
- 如果白鹭原始答案未核验，明确说来源性质
- 用户先做，老师再纠偏
- 每一步只做当前步骤，不一次把后面答案全说完

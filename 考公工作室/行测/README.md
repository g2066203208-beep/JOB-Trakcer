# 行测周训练

## 固定规则
- 每天 08:30–10:30。
- 专项日：前 50 分钟限时训练，10 分钟休息，后 50 分钟二轮训练/复盘，最后10分钟记错因。
- 周六整套模拟；周日错题回炉。
- 每次记录：题量、正确率、用时、错因。

## 一周安排
- 周一：资料分析
- 周二：判断推理
- 周三：数量关系
- 周四：言语理解
- 周五：资料+判断混合限时
- 周六：整套模拟
- 周日：错题复盘 + 最弱两类补题

## 错因标签
1. 知识不会
2. 审题错误
3. 计算失误
4. 时间不够
5. 犹豫改错

常识判断不单独占黄金2小时：放在碎片时间积累，并在整套模拟中检验。

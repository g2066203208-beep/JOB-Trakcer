# 考公工作室

这里用于长期记录考公学习进度，不与仓库现有骨骼动画工作室互相干扰。

## 考公拆分

### 1. 行测
- [行测周训练](./行测/)
- 固定时间：每天 **08:30–10:30**
- 周一资料分析、周二判断推理、周三数量关系、周四言语理解、周五混合限时、周六整套模拟、周日错题复盘。
- 每次记录：题量、正确率、用时、错因。

### 2. 申论
- [申论 DAY60](./申论DAY60/)
- 固定时间：每天 **10:40–11:40**
- 以 **白鹭 DAY60 讲解思路为主**，半月谈讲义为题目与材料依据。
- 当前：**DAY01 已完成，DAY02 总结课进行中。**

## 申论记录规则

1. 每完成一天，更新对应 DAYXX 学习日记。
2. 每天记录：题目、圈画原文、合并逻辑、最终答案、当天暴露的问题、下一次复习提醒。
3. 不把模型自行总结的内容伪装成白鹭标准答案；如为额外补充，要单独标明。
4. DAY 完成后更新进度页。

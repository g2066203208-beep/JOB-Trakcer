2. 申论以 **白鹭 DAY60 讲解思路为主**，半月谈讲义为题目与材料依据。

4. 不把模型自行总结的内容伪装成白鹭标准答案；如为额外补充，要单独标明。
5. DAY 完成后更新进度页。

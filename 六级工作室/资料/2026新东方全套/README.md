这些仓库 PDF 是从用户上传的原始扫描 PDF **逐页影印压缩**得到的轻量镜像，页数与页面顺序保持一致，用于 GitHub 内直接存档和查看。它们不是原始扫描 PDF 的逐字节副本，因此像素质量经过压缩。

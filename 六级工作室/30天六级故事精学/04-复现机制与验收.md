# 跨天复现、错题台账、课程验收

## 1. 间隔复习规则（主动回忆）
新知识学习日为 D，则安排 **D+1、D+3、D+7、D+14、D+30** 复习。超过第30天的复习继续在后续学习日安排，不因课程结尾而消失。

每个复习轮次：
- 隐藏中文，英→中识义；给中文，中→英回忆。
- 把词汇放进1句与故事相关的原创英语；把核心搭配改写为1句作文或翻译。
- 对同一个句法分别做“分析一遍＋自己造句一遍”，杜绝只读答案。
- 每次将错误分类后回收到下次复习，不凭熟悉感判断已会。

## 2. 30天精学配置
- **A层**每天20个主学词＝600个“词位”（允许重复，不可当成600个唯一新词）。
- **B层**每天50词＝1500个独立词条供听读识别；**C层**3778词为已有基础词和补充词的全量查漏。B+C为5278个不重复的公开参考词表条目，与A有重叠，**不可三层相加当成唯一词数**。详见[扩展词汇表](./VOCAB/README.md)。
- 每天8个搭配＝240个“训练位”，刻意复用高频表达；全局36个表达滚动出现。
- 两项语法共60轮训练，由20个模块循环覆盖；每5天阶段检测。
- 30个观点明确的写作题＝6逻辑类型×5次复练；每天句子，五日一篇计时长作文。
- 30个翻译主题句＋6次完整段落；中译英段落用实际字符数检查再发布。
- 30个听力专项＋30个阅读专项；5次阶段混合小测＋1次正式套题，最后仍须用未做过的真题验证迁移。

## 3. 单词/搭配「熟练」判定
| 状态 | 标准 | 下一步 |
|---|---|---|
| 0 未见 | 初次接触 | 解释音义、词性、搭配 |
| 1 眼熟 | 看得懂但想不起 | 当天2次主动回忆 |
| 2 可识别 | 听/读能正确理解 | 次日中译英输出 |
| 3 可产出 | 不看答案造句正确 | D+3 / D+7迁移 |
| 4 稳定 | D+14 / D+30仍能准确使用 | 改成低频维护 |

## 4. 错题分析不只对答案
- 听力：识音、语速、弱读、转折、长句、漏数字、同义替换、推断、注意力中断。
- 阅读：定位、词性、词义、熟词僻义、指代、逻辑转折、作者态度、过度推断。
- 作文：跑题、论证空洞、主谓一致、搭配介词、时态、连词、单复数、表达生硬。
- 翻译：漏信息、逻辑错误、句子主干缺失、翻译腔、专有名词、介词/冠词错误。

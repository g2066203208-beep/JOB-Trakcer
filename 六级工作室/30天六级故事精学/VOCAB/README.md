# 六级30天三层词汇总控：从600学习位升级至5278词的全表查漏

> 这是**词汇库的覆盖与训练规划**，不是声称30天记熟了5278个单词。原来的每日20词仅是A层精学位，不能代表六级总词汇量。

## 课程真正的词汇规模（30天）
| 层级 | 覆盖量 | 每天 | 学习要求 | 是否强制精学 |
|---|---:|---:|---|:---:|
| **A 精学输出层** | 600词位（各日20词，有跨日重复，非600个唯一生词） | 20 | 听懂、讲解语境义、词形、搭配、会说、会写、会译、自然进入剧情 | 是 |
| **B 听读高频识别层** | **1500个不重复参考词条** | 50 | 听音识义、阅读认义、同义替换；错词滚动升入A | 识别为主 |
| **C 全词表查漏层** | **3778个不重复参考词条** | 每日125或126 | 快速筛查，已会跳过，不熟的根据考试价值进入个人复习池 | 否 |
| **合计原始参考词表** | **5278个不同英文词条**（B+C，二者不重叠） | — | 覆盖传统四六级基础与六级拓展范围 | 不等于掌握 |

**重要计数说明：** A层与B/C有交集，不能把600+1500+3778相加声称5878个不同单词。B+C才是源词表5278词条的无重覆盖；A层额外强调高价值语境产出。源词表标记★的词条数为 **1253**，但★仅表示来源整理的级别，不代表2026年官方新考纲的全量清单。

## 三层自动晋级
1. **摸底**：先做A和B的快速识义；已掌握内容标记，不浪费重复背诵时间。
2. **A层**：五次主动输出（听懂、原文、造句、英译汉、汉译英），在故事中尽量自然复现；连续两次错答则降低新词负担。
3. **B层**：阅读/听力识别优先，遮盖中文抽测；反复错误且阅读常见的词升入A。
4. **C层**：只是词表完整覆盖的查漏检索，对大量基础词零重复刷；没记住但低价值的冷僻词可留待考前看。
5. **间隔复现**：D+1、+3、+7、+14、+30主动回忆错词。基于错题的计划优于机械每天背170词。

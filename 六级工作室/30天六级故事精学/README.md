## 故事骨架（原创）
主人公林澄（Lin Cheng）在一座午夜图书馆发现：所有被删掉的档案都关联到某个失踪的家人。她经历雾都侦探案、记忆学院、深海科研、历史穿越、AI伦理和公开听证会，在第30天解开“第三十一页”的意义。每个谜题要能逻辑回收；侦探、奇幻、科幻等仅借鉴类型风格；不复制《哈利·波特》等仍受版权保护的角色、具体情节或原著原文。

## 重点教材策略
- **词汇（已升级）**：每天**A层20个重点精讲输出词＋B层50个听读识别词＋C层125/126个全表快速查漏词**。B层1500个不重复词＋C层3778个不重复词，**合计覆盖参考词表5278条**；原A层600是有重复的词位，不能再被误说成“六级只有600词”。见[30天全量词汇总控](./VOCAB/README.md)。
- **固定搭配**：每日8个，共240个“搭配训练位”；36个跨题型核心搭配每日强制复用6个。
- **语法**：20个高收益句法模块，30天循环训练60次；重点服务阅读句子解析、写作准确性和翻译重组。
- **写作**：6种逻辑框架，每种重复5次，不背30份互不相干的模板。
- **听力**：长对话8题／听力篇章7题／讲话报道讲座10题；故事朗读不替代正式听力。
- **阅读**：选词填空10题／长篇匹配10题／仔细阅读10题；做真题要计时。
- **翻译**：每天1条可迁移句，五日一次完整180–200汉字模拟段落。
- **六级真题**：在新东方讲义和仓库内已归档真题的基础上出题、测验、校准；不复制到学习版造成混淆。

## 正式逐日课件发布验收
本次已经**安排A层词、扩展B/C词库、搭配、语法、重点句和题目方向**；下一阶段创作逐篇故事正文时需要：
1. 先写故事提纲（欲望、冲突、线索、解决／新悬念），再按当天词表自然植入词汇；故事好听优先，不硬塞生词。
2. 产出“纯英文朗读稿”、独立“逐句逐词讲义”、独立“考试式听力和题目”、阅读练习、写译示范与错题讲解。
3. 逐句核对英汉、语法、搭配和英语自然度；至少重点词15/20进入正文，余下练习覆盖。
4. 每日结束给出具体答题记录和错题回收。没有实际测试不得宣称满分或完全掌握。

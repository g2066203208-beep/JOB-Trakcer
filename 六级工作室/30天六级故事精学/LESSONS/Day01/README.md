# Day 01｜《雨夜没有脚印》The Footprints That Vanished

**课程状态：已编写并校对的第一天正式课件。** 三幕原创悬疑故事，正文按英文单词拆分统计 **873词**（不含标题、课程注释和训练题），**81个句子或话语单元**；独立中文逐句译文、逐词词形索引和六级专项训练。

**剧情简介（不剧透）：** 林澄带着哥哥留下的银钥匙进入午夜图书馆，随后来到1894年的伦敦，调查一起“雨后无脚印”的失踪案。一名目击者坚信自己看到了嫌疑人，然而真实的观察和由观察推出来的结论并不是一回事。最后一声钟响将案件引向Day02。

## 请按这个顺序学（朗读与精讲拆开）
1. **第一遍听故事（约6–8分钟）** → [01-纯英文故事](./01-纯英文故事.md)。使用ChatGPT朗读功能，只念三幕英文故事，不读说明和后面的中文，先不翻译。
2. **第二遍逐句精讲（约25–35分钟）** → [02-逐句译文与语法](./02-逐句精讲.md)。共81个话语单元，任何一个不懂的英文词去[02B-逐词与词形索引](./02B-逐词与词形索引.md)查原句位置。
3. **A层20核心词＋8组搭配（约12–15分钟）** → [04-可写可译的核心词精讲](./04-A层20核心词与8大搭配.md)。全部在课程中复用而不是孤立背记；另有[50个B层＋126个C层](../../VOCAB/Day01.md)用于查漏，C层已会就跳过。
4. **六级听力（约10分钟）** → [03A-纯英文长对话朗读稿](./03A-听力朗读专用脚本.md)；只听一遍，然后在[03-实战训练](./03-六级实战训练.md)做4道选择题。
5. **阅读（约15–20分钟）** → [03-仔细阅读5题＋选词填空10空＋长篇匹配5题](./03-六级实战训练.md)，优先定位证据并说明为什么排除干扰项。
6. **写作与汉译英（约20–30分钟）** → 同一份[03-实战训练](./03-六级实战训练.md)，先写后对照165词参考作文，完成短句译文；额外有约196汉字的提前训练段落与译法拆解。
7. **第三遍复听（约5分钟）** → 关掉中文，用五个词复述：claim / evidence / assume / identify / reliable，随后做间隔复习。

## 今日只记住的核心方法
**Observation（观察到的事实）≠ Interpretation（个人解释）≠ Proof（证明）。** 掌握这一区分，可以同时应用于六级听力的推断题、阅读的偷换概念题、作文中的证据论证以及翻译中的事实/判断表达。

## 量化验收
- 20个A层词至少18个英→中认义，任意8个能够在60–90秒的英语复述里正确使用。
- 能解释两种句法：**并列与主干**、**比较与部分否定**。
- 八个搭配中至少能正确造句六个；作文至少使用四个（自然优先）。
- 听力4题、仔细阅读5题、选词10空、长篇匹配5题，有错则分类回收到明日。
- 写作和翻译必须自己先写一遍，再查看范文，不能看懂答案就算学会。

## 用量说明
- 原创小说873词是**叙事朗读素材**，并不冒充六级正式听力的篇章长度；考试听力另外使用独立对话脚本。
- 题目、答案、参考作文与翻译为本课程原创模拟，并非官方真题。
- 逐句精讲是81个含短答和照片文字的单元，不等于全部是独立完整语法句。
- 六级满分只能作为质量目标，课程不会承诺30天确保得满分。

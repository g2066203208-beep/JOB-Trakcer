# 光伏支架建模｜第08节

分析方向：结构静力。内容：实体、壳与梁简化对比。
工程目标：比较支架简化方式及连接表达，追踪计算规模和适用条件。

当前状态：本机重算有结果 · 逐步骤核对中。操作手册尚未逐步验收，不能视为从零建模完整教程。

## 来源与贡献

原始模型和讲解来自用户提供的华仿CAE课程。本人工作记录：本机工程恢复、自动化检查、适用分支重算、路径故障定位及证据归档。课程模型不表述为独立商业设计。

## 已执行流程

1. 在 D 盘保存原始工程包，并记录 SHA-256；原包保持不变。
2. 用 Workbench 2024 R2 还原 2023 R1 课程归档，读取系统名称与类型。
3. 进入各 Mechanical 模型，导出对象树、材料、连接、约束、载荷、分析设置和结果对象。
4. 对原工程具有完整静力定义的分支执行清理生成数据与同步求解；欠定义分支保留待核对。
5. 检查 solve.out、RST 和 Mechanical 结果状态。发现中文路径下结果读取失败，使用全英文 D 盘工作路径验证和修复。
6. 对通过结果读取的分支导出 ANSYS 原生云图；失败图不作为有效结果。

## 按界面复核

1. 启动 ANSYS Workbench 2024 R2。使用 File → Open 打开本地 course.wbpj（第1节为 lesson01_geometry_review.wbpj）；不要仅复制 wbpj，保留同名 _files 文件夹。
2. 在 Project Schematic 找到对应系统，双击 Model 打开 Mechanical。核对模型树中的分析类型。
3. 展开 Geometry，逐个选择 Body；查看 Details 中 Material、几何类型、厚度或梁截面。对照下方系统记录。
4. 展开 Connections，逐项查看接触/连接的作用对象、类型、摩擦系数与坐标系；使用图形高亮确认选区。
5. 选择 Mesh，查看全局尺寸与局部控制。重新生成网格后记录节点数、单元数和质量；本项的完整界面逐帧补录仍待完成。
6. 展开分析分支，依次选择 Analysis Settings、载荷和支撑。逐步检查 Tabular Data，特别是预紧载荷的锁定状态。
7. 保存副本。Solve 后检查 Solution Information，记录警告、错误、收敛和最终步。
8. 选择每个结果，核对作用范围、时间/模态、单位、坐标系和显示倍率，再导出截图。
9. 将数值与解析检查、网格收敛或课程同工况结果比较；目前未闭合的项目继续标记待验收。

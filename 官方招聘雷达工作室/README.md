# 官方招聘雷达工作室

目标：持续收集、核验和巡检目标企业的**官方招聘网站 / 官方校园招聘入口**，为“秋招工作室”提供可信的一手入口。

## 核心原则

1. **官方域名优先**：招聘页位于企业官网同主域名/子域名，标记为 official-domain。
2. **官网反链可确认**：企业官网直接链接到智联、智业、前程无忧等第三方 ATS，标记为 official-linked。
3. **搜索结果绝不直接当官网**：只由搜索引擎发现、暂时无法形成官方证据链的入口进入 pending。
4. **保留证据**：记录企业官网、招聘入口、最终跳转URL、页面标题、HTTP状态、最后核验时间和页面指纹。
5. **优先服务当前求职目标**：海口/海南、土木/结构/工程管理/成本造价、新能源、电力设计、央国企、银行。

## 自动运行

GitHub Actions：.github/workflows/official-recruitment-radar.yml

- 每天 **08:30（北京时间）** 自动巡检。
- 可在 Actions 页面手动运行。
- 自动检查已知招聘入口是否可访问、是否跳转、页面是否变化。
- 对没有招聘入口的公司自动做网页发现，结果先进入待核验池。
- 结果有变化时自动提交到仓库。

## 数据文件

- companies.csv：公司种子池。可不断追加企业。
- generated/sites.json：已经确认/种子确认的招聘入口及巡检结果。
- generated/pending.json：自动发现但证据链不足的候选入口。
- STATUS.md：每次扫描后的可读摘要。
- index.html：GitHub Pages 可视化工作台。

## 验证等级

| 等级 | 含义 |
|---|---|
| verified_seed | 已人工/官方公告确认的招聘入口，自动巡检其状态 |
| official-domain | 招聘入口与企业官网属于同一注册主域名 |
| official-linked | 招聘入口为第三方 ATS，但由企业官网直接链接 |
| pending | 搜索发现，尚无充分官方证据，不得作为正式入口使用 |

## 如何扩展到更多公司

只需在 companies.csv 增加一行公司名称。即便暂时没有官网或招聘网址，自动发现器也会搜索并把候选放入 pending。

首批公司池覆盖银行、三桶油、电网/电力、新能源、中建/中铁/电建、设计院、地产央企、通信运营商、海南省属国企等，后续持续扩展。

## 与秋招工作室的关系

本工作室回答“**去哪里看官方招聘**”；秋招工作室回答“**我投了什么、下一步准备什么**”。

未经用户确认的岗位，不能因为本雷达发现招聘入口就自动记成“已投递”。
